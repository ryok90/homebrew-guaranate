# homebrew-guaranate

Homebrew tap for [Guaranate](https://github.com/ryok90/guaranate) — a
developer-friendly macOS keep-awake CLI.

```bash
brew tap ryok90/guaranate
brew install guaranate
```

The formula installs the prebuilt universal (`arm64` + `x86_64`) binary from
Guaranate's [GitHub releases](https://github.com/ryok90/guaranate/releases).
